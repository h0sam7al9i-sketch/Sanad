# سند — تطبيق الأذكار والأدعية والمسبحة

نسخة 1.0 تعمل بدون إنترنت وبدون إعلانات.
تم حذف قسم القرآن بناءً على طلب المستخدم.

الأقسام:
- الأذكار: الصباح، المساء، بعد الصلاة، النوم، وأذكار عامة.
- الأدعية: مجموعة أكبر من الأدعية المختارة.
- المسبحة الإلكترونية: عداد محفوظ حتى بعد إغلاق التطبيق.

الأيقونة هي الصورة التي أرسلها المستخدم.

## بناء APK تلقائياً من الهاتف عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub باسم `Sanad`.
2. ارفع محتويات هذا المجلد إلى المستودع.
3. افتح تبويب Actions.
4. شغّل workflow باسم `Build Sanad APK`.
5. بعد نجاح البناء، افتح صفحة التشغيل ثم قسم Artifacts.
6. نزّل `sanad-debug-apk` وفك ضغطه، وستجد `app-debug.apk`.

لا يحتاج البناء إلى Android Studio على هاتفك.
